# Data Cleaning & Visualization Project – Iris Dataset
## Project Overview
This project focuses on **data cleaning, preprocessing, and visualization** using the Iris dataset. The goal is to transform raw data into clean, structured data and generate meaningful visual insights through exploratory data analysis.
## Objectives
- Handle missing values
- Remove duplicate records
- Detect and treat outliers
- Perform exploratory data analysis (EDA)
- Create visual reports and dashboards
- Save the cleaned dataset for future use
## Tools & Libraries Used
- **Python**
- **Pandas** – data manipulation and cleaning
- **NumPy** – numerical operations
- **Matplotlib** – basic data visualization
- **Seaborn** – advanced statistical visualizations
## Dataset Information
The Iris dataset contains measurements of iris flowers from different species.
### Features:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width
- Species (Target Column)
## Project Workflow
### 1. Data Loading
- Imported the Excel dataset using Pandas
- Inspected dataset structure and summary statistics
### 2. Data Cleaning
- Checked for missing values
- Filled missing numerical values using median
- Removed duplicate rows
- Standardized column names
### 3. Outlier Handling
- Applied the **IQR (Interquartile Range)** method
- Capped extreme values to reduce outlier impact
### 4. Data Visualization
Generated multiple visualizations to identify patterns and relationships:
- **Count Plot** – species distribution
- **Pair Plot** – relationships between features
- **Correlation Heatmap** – feature correlations
- **Boxplots** – outlier analysis
- **Histograms** – feature distributions
## Key Insights
- The dataset required minimal cleaning.
- Duplicate entries were removed.
- Outliers were detected and treated.
- Petal measurements show strong separation among species.
- Strong correlations exist between petal-related features.
